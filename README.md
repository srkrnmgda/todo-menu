# To-Do Menu

MacOS menu bar to-do scratchpad. Stays entirely in the menu bar.

Unzip ToDoMenu.zip into Applications to install.

---

## Keybinds

### Global Shortcuts
- Option + T: Open/Close

### Navigation and Use
- Option + W: Pin/Unpin
- Arrow up/down: Navigate tasks
- Return (on input field): Create new task
- Return (on past task): Edit
- Backspace (on past task): Delete task
- Shift + Up/Down (on old task): Reorder tasks
